# 🚀 Quick Start - Controle Financeiro

## Setup Rápido em 3 Passos

### 1️⃣ Configurar Banco de Dados (Uma vez apenas)

1. Acesse: https://pebwoerzslfzhjptyjwh.supabase.co
2. Vá em **SQL Editor**
3. Execute o arquivo: `setup-financial-control-franca-private.sql`
4. Aguarde: **"CONFIGURAÇÃO CONCLUÍDA COM SUCESSO!"**

### 2️⃣ Acessar Franca Private

1. Na tela de login, clique **3x** em "Bruno Assoni"
2. Login: `admin@francaprivate.com` / `1020`
3. Você verá: **"🔒 Sistema Franca Private Ativado"**

### 3️⃣ Usar o Controle Financeiro

1. Clique em **"Controle Financeiro"** no menu
2. Clique em **"Atualizar Caixa"** (aguarde ~5 segundos)
3. Veja as comissões de todas as empresas
4. Adicione despesas com **"Nova Despesa"**
5. Veja o relatório automaticamente atualizado

## 💡 Dicas

✅ Clique "Atualizar Caixa" regularmente para ver dados atualizados  
✅ Use categorias consistentes para melhor organização  
✅ O campo "Observações" ajuda a lembrar detalhes depois  
✅ O cálculo de reinvestimento (15%) é automático  
✅ Você pode excluir despesas se errar

## ⚠️ Atenção

- ⏱️ A primeira busca pode demorar ~5 segundos

## 🆘 Problemas Comuns

**Menu não aparece?**  
→ Faça login como Franca Private (3 cliques em "Bruno Assoni")

**Erro ao buscar comissões?**  
→ Verifique sua conexão de internet

**Erro ao adicionar despesa?**  
→ Execute o script SQL de setup primeiro
